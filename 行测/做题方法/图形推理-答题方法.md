> 2026-11-25 建。判断推理做题方法里的 1.1–1.8 是知识清单，这一份是**手上动作**：每题按顺序做什么、先看什么、卡住换哪一步。

## 〇、一句话总纲

**三看定族，按族动手；一族不成就换族，别在一条道上加时间。**

---

## 一、40 秒固定流程（每题都走，不许跳）

| 秒 | 动作 | 说明 |
|---|---|---|
| 0–5 | 定题型 | 顺推 / 九宫格 / 两段 / 分组 / 交换 / 立体，题型决定套路 |
| 5–10 | 三看定族 | 元素是相同的、相似的，还是全不同 |
| 10–25 | 按族动手 | 相同→位置；相似→样式；不同→数量；数不出→属性 |
| 25–35 | 用选项反验 | 拿一个最像的选项回头套一遍，看规律是否唯一 |
| 35–40 | 卡住就换族 | 数量族数不出，立刻转属性族；不要继续数 |
| >60 | 标记跳过 | 最后统一回来，用"重新分族"再看一眼 |

两条铁律：

1. **同一题最多在同一个族里花 15 秒。**超过就是规律找错了，不是眼力不够。
2. **每题做完说一句"我用的是哪条规律"。**说不出来 = 没做完，选对了也算蒙的。

## 二、三看定族（判断组成的三个抓手）

| 看什么 | 相同 | 相似 | 全不同 |
|---|---|---|---|
| 外框轮廓 | 一模一样 | 同源但变形 | 各有各的外框 |
| 内部填充（黑块、黑点、阴影） | 个数、位置一致 | 数量有增删 | 每图都不同 |
| 线条来源 | 同一批线在动 | 部分线保留 | 各画各的 |
| 结论 | **位置族** | **样式族** | **数量族**（数不出转属性族） |

一句记法：**它只是"动了"，不是"变了"——就是位置；它"变了一点"——是样式；它"全变了"——去数数。**

## 三、四个族，各族的第一个动作

### 3.1 位置族（元素相同）

**第一个动作**：抓一个**不对称的特征点**（小黑点、缺口、尖角、唯一的长线），在每幅图上标出它的位置。

| 规律 | 怎么定 | 常见坑 |
|---|---|---|
| 平移 | 先定方向（顺/逆时针、上下左右），再定步长（恒定／等差／交替／循环） | 方向看反；步长当成"每次一格"其实是"隔一格" |
| 旋转 | 先定角度（45°／90°／180°），再定方向 | 角度和方向同时猜，两个都错就全乱 |
| 翻转 | 看手性：转一下能重合＝旋转；必须翻面才重合＝翻转 | 把镜像当旋转 |
| 分开看 | 黑块数量不同就分组：1 块、2 连块、3 连块各走各的 | 混在一起找，永远找不到 |

**方向别靠感觉**。拿笔在草稿上画个小圈，按 1→2→3 标出位置顺序，再看是顺时针还是逆时针。今天 Q006 就是黑块从"1 块"到"2 连块"到"3 连块"，三组都按顺时针排——A、B、D 三个选项全是逆时针，只这一条就能排掉。

### 3.2 样式族（元素相似）

**第一个动作**：把相邻两幅图叠在一起，问一句"多出来的是什么、少掉的是什么"。

| 规律 | 操作 | 常见坑 |
|---|---|---|
| 相加 | 两图直接合 | — |
| 求同 | 只留重合部分 | 把"重合"看成"相加" |
| 求异 | 只留不重合部分 | 最常见，也最容易和"求同"看反 |
| 旋转 + 运算 | 先转再算，或先算再转 | **只做了一半**：转完忘了算，或算完忘了转 |
| 黑白运算 | 同位置逐一取色，先把规则表推出来再套 | 套用上一题的规则 |
| 遍历 | 每行每列各元素出现一次，缺谁补谁 | 只横着看，忘了竖着也能看 |

**运算题必须把两步都写在纸上**：写"① 图1 逆时针 90°② 与图2 求异"，一行字，比在脑子里转靠谱。今天 Q004 九宫格，第一行是"图1 逆时针转 90° 再与图2 求异"，第二行同规律，第三行照做只剩中间的圆——只要漏掉"转"这一步，就会选到 B 那种"只求异"的结果。

### 3.3 数量族（元素不同，最高频）

**第一个动作**：数**点**。点不行数线，线不行数面，面不行数角、数素。

| 看到什么 | 数什么 | 备注 |
|---|---|---|
| 线条交叉多 | 交点数 | 十字、T 字、X 形都算交点 |
| 有相切、有挨着 | 切点数 | 和交点分开数，别混成一锅 |
| "日"字、"田"字、汉字、字母、有出头端点 | 笔画数 | 数奇点，见下 |
| 图被分割成若干块 | 面数（封闭区域） | 最外圈不算"面" |
| 全是直线／全是曲线／混着 | 直线数、曲线数 | 外形规整时优先 |
| 多个小图形拼一起 | 元素种类数、部分数 | 相同算一种，挨着算一部分 |

**数列形态**（数出来往上套）：恒定 / 等差 / 等比 / 对称 / 奇数项偶数项各成规律 / 前两图运算得第三图。

**一笔画（每年 1–2 题，白给的分）**

- 奇点＝从这一点引出**奇数条**线的点。
- 奇点数 0 或 2 → 一笔画；4 个 → 两笔；6 个 → 三笔（笔数＝奇点数÷2）。
- **端点也算奇点**（只连一条线），这是最常漏的一处。

今天 Q002 的图是"日"字变形，还带出头端点——这就是把"数奇点"写在脸上的信号，题干每幅都是一笔画，选项里只有 D 是一笔画。

今天 Q008 的图线条交叉、还有相切，考点是**切点数**全是 1，不是交点数。

### 3.4 属性族（数量数不出时的兜底）

**第一个动作**：看对称——先画对称轴，再看是不是还能中心对称。

| 属性 | 怎么判 | 常见坑 |
|---|---|---|
| 轴对称 | 沿一条线对折能重合，数轴有几条、朝哪个方向 | 只数条数，不看方向 |
| 中心对称 | 转 180° 与原图重合（平行四边形是典型） | 把"轴+中心"当成"只有轴" |
| 曲直 | 全直 / 全曲 / 曲直混合 | 混着也算一类，别硬分 |
| 开闭 | 全封闭 / 半开半闭 / 全开 | — |
| 图形间关系 | 相交 / 相切 / 相离 / 包含 / 覆盖 | 只看单个图，忘了看图与图之间 |

**对称的三个档位要背住**：只轴对称、只中心对称、两者兼有。分组题里最常按这三档分。今天 Q010 就是——①③⑥ 既轴又中心，②④⑤ 只有轴，我按"都轴对称"一刀切，就分成了 ①③⑤ 和 ②④⑥。

**看到等腰三角形、等腰梯形、正多边形，先想对称；看到圆和"Z"形，想中心对称。**

## 四、六种题型的套路

| 题型 | 长什么样 | 套路 |
|---|---|---|
| 顺推 | 一列 5–6 图，问下一图 | 按一族的规律往后推一步，别一次看全 |
| 九宫格 | 3×3，右下缺 | **先横着看**（九成按行），行不通再看列、看对角 |
| 两段式 | 前 5 图 + 后 4 选项 | 前段定规律，后段照做；两段规律必须同一条 |
| 分组分类 | 6 图分两组 | 找能**正好 3+3** 的规律；分出来 1 vs 5 就是规律错了 |
| 交换位置 | "哪两个交换后有规律" | **先找全图恒定量**（交点数、重合边数、面数），再看这个量怎么移动 |
| 立体 | 六面体、截面、三视图 | 相对面→时针法→公共边；截面记"正方体切不出七边形、切不出直角三角形" |

**交换位置题单独说**：它永远是"先找一个每幅图都一样的量，再看这个量在移动"。今天 Q005 每幅图都是六边形被切成 3 个面，其中只有一个面有 3 条边贴着外框；这 3 条重合边从①到④每次顺时针移一条边，交换⑤⑥之后才连贯。我选了 ④⑤，说明只看了一格就停手——**移动类要一路数到第 6 幅图，别数到一半就下结论。**

## 六、8 分钟 10 题的节奏

- 0–2 分钟：先扫一遍 10 道，把"一眼有族"的 3–4 道做掉（位置族、样式族通常快）。
- 2–5 分钟：做数量族的 4–5 道，每道限定 45 秒，数不出立刻转属性。
- 5–7 分钟：回来啃剩下的，重点用"换族"再试一次。
- 最后 1 分钟：只检查"方向类"和"分类类"两道最容易反的题。

跳题不丢人，**在同一族里死磕才丢分**。

## 七、口诀总表（考前扫一眼）

- 相同看位置，相似看样式，不同看数量，都不行看属性。
- 先定族，再数数；一族 15 秒不出手，换族。
- 交叉多→交点；相切→切点；"日"字出头→奇点（笔画）。
- 一笔画：奇点 0 或 2；**端点也算奇点**。
- 方向先画圈标序，再判顺逆。
- 运算把"转"和"算"分开写在纸上。
- 交换题：先找每图都一样的那个量，再数它怎么走。
- 分类题必须 3+3；1 vs 5 就是规律错。
- 对称三档：只轴、只中心、两者兼有。

## 八、两周怎么练（照这个走）

1. **每天一组 10 题 8 分钟**，做完不复盘题目，只复盘"族"：每题写一个字母（位／样／数／属）。
2. **错题写一句"我漏了哪个动作"**，例如"漏了数切点""忘了先转再算"，写在图推错题旁边。
3. **三天统计一次族分布**：哪一族错 2 道以上，第二天 10 题专门从那一族抽。
4. **一周后用这套流程做 20 题不限时**，目标是每题都能说出族和动作，正确率再谈速度。

图推是行测里**唯一能靠"背规律+练动作"直接提分**的模块。别把它当智力题，它就是一张检查清单——一眼一条，挨着过。
