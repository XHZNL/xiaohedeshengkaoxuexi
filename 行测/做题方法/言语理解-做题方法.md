# 言语理解 · 做题方法

> 整理：鲸鱼娘　｜　2026-11-01　｜　体系：花生十三（语境对应 / 主题词 / 选项范围）
> 定位：40 题 35 分钟。**这模块靠"找对应"，不靠语感**——语感只能到 60%，对应能到 90%。
> 配套：`公考错题本.md` 第一模块，那儿四条错题正是这份文档的活教材。

---

## 〇、一句话原则

> **凡是靠"读起来顺"选出来的答案，八成是错的。**
> 正确答案一定有**出处**——上下文里有个词、有个关联词、有个主题词，在跟它呼应。找不出来，就是还没读懂。

## 一、逻辑填空（20 题，分值最重）

### 1.1 核心：四类对应（找暗示）

每个空在上下文里都有"暗示"，先找暗示再选词。

| 对应类型 | 标志 | 怎么用 |
|---|---|---|
| **反义对应** | 但是、然而、却、反而 | 空格与提示词意思相反 |
| **并列对应** | 和、与、以及、同时、"、" | 空格与并列项意思相近 |
| **递进对应** | 甚至、更、不仅…还 | 空格比提示词程度更重 |
| **解释对应** | 即、也就是说、冒号、破折号 | 后半句就是在解释空格 |

**操作四步**：
1. 圈出空格前后 10 字内的关联词 / 提示词
2. 判断是哪类对应
3. **用自己的话把空格的意思说出来**（这一步最关键，别直接看选项）
4. 拿自己那句话去选项里找最匹配的

> 顺序错了就全盘错：**先自己想，再看选项**。先看选项会被"读起来顺"带跑。

### 1.2 三轴辨析（两空都通时用）

**轴一：语素差异**
拆词看不同的那个字。
- 遏制（制=控制）vs 遏止（止=停止）
- 权力（政治）vs 权利（利益）
- 篡改（改内容，贬）vs 窜改（改文字，中性偏贬）

**轴二：程度轻重**
语境有"严重""极其""彻底"→ 选重的；语境温和 → 选轻的；拿不准 → 选中间。

常见梯度：批评 < 抨击 < 鞭挞｜怀疑 < 质疑 < 否定｜阻碍 < 阻挠 < 破坏

**轴三：感情色彩**
褒义语境选褒义词，贬义选贬义词，客观描述不要带情绪。

> 三条轴按顺序试：语素 → 程度 → 色彩。多数题在第一条就定了。

### 1.3 固定搭配（白给的 2–3 分）

- 汇聚 / 凝聚 **力量**
- 提高 / 提升 **水平**
- 推动 / 促进 **发展**
- 维护 / 捍卫 **权益**
- 履行 / 践行 **承诺**
- 传承 / 弘扬 **文化**
- 培育 / 厚植 **精神**
- 破解 / 化解 **难题**
- 激发 / 释放 **活力**
- 筑牢 / 夯实 **基础**

**易错**：提高范围 ✗ → 扩大范围 ✓｜改善缺点 ✗ → 改正缺点 ✓

### 1.4 关联词定位（做不对时的兜底）

转折（但是/然而）→ 重点在后；递进（甚至/更）→ 重点在后；因果（因此/所以）→ 结果才是重点；对策（应该/必须/需要）→ 对策是重点。

**填空呼应的是"重点那一半"，不是前半句的语气。**

### 1.5 成语：三栏记忆法

**意思 / 适用对象 / 褒贬**，三栏都得记。字面像，用法未必像。

高频"对象错"陷阱（最容易踩）：
- 一叶知秋：由细微迹象**推知趋势**，不是"以小见大"
- 汗牛充栋：只形容**书多**（不含资料、观点）
- 洛阳纸贵：形容**著作**流传广
- 相敬如宾：只用于**夫妻**
- 豆蔻年华：只用于**十三四岁少女**
- 美轮美奂：只形容**建筑**
- 首当其冲：首先受到**冲击**，不是"首先做到"

> 你错的那道（盆景题）就是这一栏：一叶知秋是"推知趋势"，文段讲"盆小景大"，选咫尺千里。**不是意思不对，是对象不对。**

## 二、片段阅读（17–18 题）

### 2.1 中心理解（最多，8–10 题）

**识别**："主要说明 / 意在 / 强调的是 / 主旨"。

**三步走**：
1. **找中心句**：首句（总分）、尾句（分总）、转折递进后（承上启下）
2. **抓主题词**：反复出现的词，选项必须包含；不含的直接划掉
3. **对策优先**：文段"提出问题 + 给对策"时，答案选对策不选问题

**排除四类错误选项**（这段背下来）：
- **范围过大 / 过小**：文段说"部分"，选项说"全部"
- **加戏**：出现"过度""弊大于利""根源在于""决定"这类文段没做的判断
- **偷换主体**：文段说企业，选项说政府
- **只提问题不给对策**：文段明明给了对策

> 你错的那道（晒娃题）就是"加戏"：文段在讲"对别人的影响"，A 项却写成"过度晒娃弊大于利"——**"过度"和"利弊权衡"都是文段没说的**。

### 2.2 细节判断（3–5 题）

**识别**："以下说法正确 / 错误 / 符合 / 不符合"。

**六陷阱**（逐个对）：

| 陷阱 | 表现 |
|---|---|
| 偷换概念 | 换了主体或对象 |
| 偷换时态 | "将"变"已"、"可能"变"必然" |
| 偷换范围 | "部分"变"全部"、"约"变"超过" |
| 偷换语气 | 可能 → 一定 |
| 无中生有 | 文段压根没说 |
| 正反颠倒 | 上升写成下降 |

**做法**：选项关键词 → 回文定位 → 逐字比对。**不要凭印象**，务必回到原文那一句。

### 2.3 标题填入（1–2 题）

优先级：**主题词 > 概括性 > 吸引力**。
生动新颖排最后——标题首先得对，其次才是好看。

### 2.4 语句填入（1–2 题）

看位置：首句概括后文、中间承上启下、尾句总结前文。
两头都要接得上：**既看前一句，也看后一句**，只看一边容易选到半对。

### 2.5 下文推断

看尾句话题，顺着往下讲；**前文已经讲过的排除**。

## 三、语句表达：排序（2–3 题）

四步，按顺序做，别通读：

1. **看首句**：代词开头、关联词后半句、举例——都不能做首句
2. **找捆绑**：代词（这/那/其）前必须有指代对象；关联词配对（虽然…但是）；顺序词（首先…其次）
3. **看尾句**：总结、对策、展望
4. **合并**：首尾 + 捆绑三重锁定

**技巧**：先看选项的分组差异，两组选项首句不同 → 只判首句就能砍掉一半。

---

## 四、篇章阅读（副省级 2 篇 10 题）

1. **先看问题**，带着问题读
2. 定位段落，别通篇精读
3. 答案多是**同义替换**，原词照抄反而要警惕
4. 先做细节题（定位快），后做主旨题

## 五、你的四个错因（对号入座）

错题本第一模块那四个标签，不是记录用的，是**考场上要防的四个动作**：

| 错因标签 | 考场上的动作 |
|---|---|
| **对应没找到** | 每空必须圈出呼应词。圈不出来就说明没读懂——**回到文段再看一遍，别急着选** |
| **成语对象错** | 成语三栏：意思 / 对象 / 褒贬。**先问"这个词能不能用在这类事物上"** |
| **语义程度偏** | 找语境的强度信号（严重、极其、彻底 vs 略微、有所），再定轻重大小 |
| **选项加戏** | 选项范围 ≤ 文段范围。见"过度""弊大于利""根源在于""必然"—先当嫌疑人 |

四个标签里，「对应没找到」和「选项加戏」占你错题的一半。这两条各对应一个动作：
**找呼应词**、**给选项划范围**。

## 六、时间分配（35 分钟 40 题）

| 部分 | 题量 | 时间 |
|---|---|---|
| 逻辑填空 | 20 | 15 分钟（45 秒/题） |
| 片段阅读 | 17–18 | 17 分钟（1 分钟/题） |
| 语句表达 | 2–3 | 3 分钟 |

**单题超过 90 秒立刻选一个走**。言语的题感靠节奏，卡在一道题上，后面全乱。

**两个警示**：
- 逻辑填空别反复改答案，第一遍找过对应的那个就是最稳的
- 中心理解别通读全文，先看首尾句和关联词

## 七、易错点汇总

| 坑 | 说明 |
|---|---|
| 凭语感选 | 语感只能到 60%，对应能到 90% |
| 先看选项 | 被"读起来顺"带跑，一定先自己想 |
| 忽略关联词 | 转折、递进后面才是重点 |
| 主题词遗漏 | 不含主题词的选项直接划掉 |
| 成语望文生义 | 不刊之论 = 不可更改（褒义），不是"不能刊登" |
| 程度不匹配 | 语境重选重词 |
| 选项加戏 | 文段没做的判断，选项替它做了 |
| 排序通读 | 从首句和捆绑切入，别整段读 |

---

## 八、口诀汇总

- **逻辑填空**：先想意思，再看选项；找不到对应就不选
- **四类对应**：反义、并列、递进、解释——先判类型再填词
- **两空都通**：比语素、比程度、比色彩
- **成语**：意思 / 对象 / 褒贬，三栏缺一不可
- **中心理解**：找中心句、抓主题词、对策优先
- **排除**：范围过大过小、加戏、偷换、只提问题
- **细节判断**：回原文，一字一字比
- **排序**：首句 → 捆绑 → 尾句，三重锁定
