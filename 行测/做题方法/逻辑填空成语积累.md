# 逻辑填空·成语积累（全量版）

> 整理：鲸鱼娘　｜　2026-11-11 初版、2026-11-25 补齐至 26 道成语错题
> 源：[言语理解-成语错题](../错题/言语理解-成语错题.md)（26 道）＋ [言语理解错题](../错题/言语理解.md) 里的成语类
> 只收**成语**（含当年的干扰项）。实词题（刻板/妥帖、解脱/解放、嵌入/融入、壁垒/门槛、晦涩/有限这类）留在原册按题对位。
> 用法：每天言语前扫一组；考前只看「我的坑」列和第八节口诀；做题时任何成语先过**三栏——意思 / 对象 / 时机**，再比褒贬和程度。

## 一、对象坑：意思对，说错了人

成语的适用对象是硬门槛，口语里将错就错，考试里就是错。

| 成语 | 意思 | 对象 | 色彩 | 我的坑（题号） |
|---|---|---|---|---|
| 良莠不齐 | 本义庄稼苗与杂草，引申为人品好坏混杂 | **人、品质**；不修饰信息、质量 | 贬 | 拿它修饰「信息质量」，对象错（56） |
| 一叶知秋 | 由细微迹象推知趋势 | 趋势、时局，是**预见** | 中性 | 盆景讲盆小景大，无预见义（02、98） |
| 咫尺千里 / 尺幅千里 | 方寸之间容纳千里之势 | 盆景、园林、山水画 | 中性偏褒 | 与「一叶知秋」是容纳 vs 推知（98） |
| 曲高和寡 | 曲调越高，能跟着唱的人越少，比喻知音少 | 作品、言论、人 | 中性偏褒 | 把「风格将绝迹」读成了「清高」（21） |
| 岌岌可危 | 处境十分危险 | 人、局势、组织 | 贬 | 不接「风格」（21） |
| 江河日下 | 像江水一天天往下流，情况一天天坏下去 | 局势、事业 | 贬 | 不接「风格」（21） |
| 管中窥豹 | 从竹管看豹，只见一片斑纹，所见片面 | 认识、见识 | 贬 | 02 干扰项 |
| 排难解纷 | 排除危难、解决纠纷 | 纠纷、危难 | 中性 | 与「办小事」完全不搭（52） |
| 指手画脚 | 说话时手脚乱动示意；引申为无资格乱加指点 | 人的**行为** | 贬 | 第二空要的是「姿态」，它是行为（56） |
| 直捣黄龙 | 直捣敌人巢穴取胜 | **军事**，必须有「敌人」 | 褒 | 拿它形容改革，改革不打仗（61） |
| 相形见绌 | 跟同类一比，显得不如 | 同类之间**比大小** | 中性 | 比体量用，比光彩才用黯然失色（91） |
| 黯然失色 | 相比之下暗淡无光 | 光彩、名声、颜色 | 中性偏贬 | 91 我选的，对象错 |
| 各执一词 | 各说各的，互不相让 | 主语必须是**人／各方** | 中性 | 主语是「研究结果」，不能各执一词（102） |
| 一如既往 | 跟以前一样**做** | 人的做法，多作状语 | 中性 | 主语是「宗旨」这种抽象名词，配不上（110） |
| 始终不渝 | 自始至终不改变 | 宗旨、信念、初心、友谊 | 褒 | 110 正确 |
| 自以为是 | 自己认为自己对 | 人、某一方 | 贬 | 它只说「自认对」，不说「彼此不一致」（116） |
| 朴实无华 | 朴素不华丽 | 文笔、样式、生活 | 中性偏褒 | 说「愿望」用不上（121） |
| 络绎不绝 | 行人车马来来往往接连不断 | **路上的人马车船** | 中性 | 拿来形容「报名交钱」，对象错（137） |
| 趋之若鹜 | 像鸭子成群跑过去，争相追逐不好的事物 | 众人追逐**不好的东西** | 贬 | 137 正确：作者在讽刺高价游学 |
| 力有不逮 | 力量达不到 | 能力、规范、手段 | 中性 | 「深入不进去」＝够不着（130） |
| 力不从心 | 心里想做却做不到 | 主语多是**人** | 中性 | 「法律规范力不从心」搭配勉强（130 干扰） |
| 顾此失彼 | 顾了这边丢了那边 | 两件事同时要顾 | 中性 | 「难以深入其中」不是顾不过来（130 我选的） |
| 美轮美奂 | 房屋高大华美 | 建筑 | 褒 | 56 拓展高频 |
| 汗牛充栋 | 书多得牛马出汗、堆满屋 | 书籍多 | 中性 | 同上 |
| 相敬如宾 | 夫妻互相敬重 | 夫妻 | 褒 | 同上 |
| 鳞次栉比 | 像鱼鳞梳齿一样排列密集 | 房屋、船只 | 中性 | 同上 |
| 巧夺天工 | 人工的精巧胜过天然 | 人工制品 | 褒 | 同上 |

**记法**：对象这一栏，一律连对象一起背。只背释义，等于没背。

## 二、时机坑：事前 / 事中 / 事后

| 成语 | 意思 | 时间位置 | 色彩 | 我的坑（题号） |
|---|---|---|---|---|
| 未雨绸缪 | 趁天没下雨先修缮房屋，比喻事先做好准备 | **事前** | 中性偏褒 | 51 我选的；「从而更好地」是结果，不能接事前 |
| 防患未然 | 在祸患发生前就加以预防 | 事前 | 中性偏褒 | 同 51 一类 |
| 防微杜渐 | 错误刚冒头就制止，不让它发展 | 事中·防小变大 | 中性 | 对象是错误、弊端（51 拓展） |
| 亡羊补牢 | 羊丢了再修羊圈，出事后及时补救 | 事后 | 中性 | 51 拓展 |
| 化险为夷 | 使危险转为平安 | 事后（已遇险并脱险） | 中性 | 文中没有险情发生（51 干扰） |
| 趋利避害 | 趋向有利的一面，避开有害的一面 | 过程／结果 | 中性 | 51 正确：既教辨骗局又教设健康模式 |
| 杀鸡取卵 / 竭泽而渔 | 取眼前利益，断长远根本 | **有今天和明天的对照才用** | 贬 | 「唯利是图」缺这根时间轴（64） |
| 唯利是图 | 只图利益 | 只讲贪财，**无时间轴** | 贬 | 64 我选的，只有「贪」没有「断后路」 |

**判据**：看到「从而、进而、最终、更好地」——一律往过程/结果找，**不接事前**。

## 三、褒贬坑：同一个意思，色彩各不相同

| 成语 | 意思 | 色彩 | 备注（题号） |
|---|---|---|---|
| 林林总总 | 形容众多而杂乱 | 中性 | 13 正确：与「众声喧哗」并列，只表多而杂陈 |
| 泥沙俱下 | 泥土和沙子随水一起冲下来，好坏混杂 | 贬 | 56 正确（配「芜杂」）；13 首空是中性的，不能借下文的贬义 |
| 光怪陆离 | 现象奇异、色彩繁杂 | 贬 | 13 干扰 |
| 多姿多彩 | 丰富多彩 | 中性偏褒 | 13 干扰 |
| 蒸蒸日上 | 事业天天向上发展 | 褒 | 56 与「芜杂」矛盾 |
| 恒河沙数 | 像恒河里的沙一样多 | 中性 | 56 只表多，不表好坏混杂 |
| 各行其是 | 各自按自己认为对的去做、各自为政 | 贬 | 26 正确：配「合成谬误」 |
| 各尽所能 | 各自尽自己的能力去做 | 褒 | 26 方向反 |
| 各有千秋 | 各有各的长处 | 褒 | 14 正确、26 干扰 |
| 各擅胜场 | 各有各的擅长 | 褒 | 14 干扰（与各有千秋近义） |
| 各式各样 | 样式多种多样 | 中性 | 26 只表样式多，与「合成谬误」无关 |
| 莫衷一是 | 意见分歧，得不出统一结论 | 中性 | 116 正确：研究结果各说各的 |
| 屡见不鲜 | 见得多了，不觉得稀奇 | 中性 | 116 正确：历史上、世界上都常见 |
| 数不胜数 | 多到数不清 | 中性 | 116 我选的：只说数量多，没有「见怪不怪」那层 |
| 拒之门外 | 把人挡在门外，不肯接纳 | 中性偏贬 | 117 我选的：与「包容审慎」太对称，但钉子钉在第二空 |
| 开诚布公 | 坦率诚恳地表明心意 | 褒 | 117 我选的，方向对不上「本地／非本地」 |
| 如芒在背 | 像芒刺扎在背上，形容极度不安 | 中性偏贬 | 117 正确 |
| 一视同仁 | 同样看待，不分厚薄 | 褒 | 117 正确：对应「本地／非本地」 |
| 广开言路 | 打开进言的渠道 | 褒 | 47 正确，做法／渠道层 |
| 从善如流 | 乐于接受好意见 | 褒 | 47 我选的，态度／结果层，与「广谋良策」不同层 |
| 趋之若鹜 | 争相追逐不好的事物 | 贬 | 137 正确 |
| 前仆后继 | 前面的倒下，后面的紧跟 | 褒 | 137 干扰（不怕牺牲，不是报名） |
| 纷至沓来 | 接连不断地到来 | 中性 | 137 干扰（人多，但不含争抢义） |

**判据**：并列空**只借并列那一句的色彩**，别去借下文的评价（13）。作者在讽刺，就别选中性词（137）。

## 四、程度与方向坑

| 成语 | 意思 | 提醒（题号） |
|---|---|---|
| 大相径庭 | 彼此相差很远，大不相同 | 只表「差别大」，不论优劣（14） |
| 相辅相成 | 两件事互相配合、互相补充 | 14 干扰：文段讲各有所长，不是「配合」 |
| 无关痛痒 | 与自身利害没有关系 | 52 程度过绝：真无关就不会「息息相关」（52） |
| 旁枝末节 | 事情的非主要部分、细枝末节 | 52 正确：正是「不屑办小事」的心理理由 |
| 一概而论 | 用同一标准看待、处理不同的人或事 | 04 正确：后接「部分城市／部分时段」的限定 |
| 妄下结论 | 轻率地下判断 | 04 干扰：语气偏指责，与理性分析不搭 |
| 刻舟求剑 | 拘泥旧法，不知变通 | 82 正确：对应「未知领域」 |
| 画地为牢 | 自己划个圈困住自己，自我设限 | 82 我选的：与「守株待兔」并列只是像，程度与方向都偏 |
| 守株待兔 | 死守旧经验等运气 | 82 题干原词，与「刻舟求剑」是两条线 |
| 敢为人先 | 敢于做别人没做过的事 | 82 正确：对应「大胆探索」 |
| 大展拳脚 | 充分施展本领 | 82 我选的：方向对，但语体太俗 |
| 革故鼎新 | 破除旧的，建立新的 | 61 正确 |
| 痛不欲生 | 悲痛得不想活下去 | 126 正确：极悲 |
| 伤心欲绝 | 伤心到极点 | 126 我选的：程度够，但和「悸动」不配 |
| 肝肠寸断 | 形容极度悲痛 | 126 近义；别和「嚎啕大哭」撞车 |
| 不言而喻 | 不用说就能明白 | 121 正确：配「道理、事实」 |
| 如芒在背 | 极度不安（见第三节） | 117 |

**「像」和「是」的分界**：两空题只要有一空「方向偏半档」，整题就废。写完先问「这一空要的到底是哪种义」，再拿选项比。

## 七、成组对照（错题本里反复出现的几组）

**1. 小中见大两兄弟（02、98）**
- 咫尺千里 → 方寸**装下**千里（盆景、园林、山水画）
- 一叶知秋 → 由一片叶**推知**秋天（预见趋势）
- 判据：说体量用前者，说预见用后者

**2. 关系定性四选（14）**
- 各有千秋 / 各擅胜场 → 各有优势，谁替代不了谁
- 大相径庭 / 截然不同 → 差别大，不论优劣
- 相辅相成 → 互相配合
- 判据：文段是「你做不到我能做」→ 各有千秋

**3.「各」字四兄弟（26）**
- 各行其是（贬，各自为政）｜各尽所能（褒）｜各有千秋（褒）｜各式各样（中性）
- 一字之差褒贬立变，先定褒贬再定义

**4.「多」的六种说法（13、56、116）**
- 林林总总（多而杂陈）｜形形色色（繁多）｜泥沙俱下（好坏混杂，贬）｜光怪陆离（奇异，贬）｜恒河沙数（极多）｜屡见不鲜（见得多、不稀奇）
- 判据：说的是「多」「杂」，还是「见惯了」

**5. 事前/事中/事后（51）**
- 未雨绸缪、防患未然（事前）｜防微杜渐（事中）｜亡羊补牢、化险为夷（事后）｜趋利避害（过程）

**6. 旧法三兄弟（82、61）**
- 刻舟求剑（拘泥旧法）｜画地为牢（自我设限）｜守株待兔（死等旧经验）
- 反面：革故鼎新（去旧立新）

**7. 依附三兄弟（124）**
- 皮之不存，毛将焉附 → 依附者失去依托（**靠它活**）
- 覆巢之下，安有完卵 → 同一整体里的成员一起遭殃（**一起完蛋**）
- 城门失火，殃及池鱼 → 本身无关却被牵连（**白挨刀**）
- 判据：菟丝草对寄主＝寄生依附，只能选第一个

**8. 光泽二兄弟（91）**
- 相形见绌 → 比大小、比高低
- 黯然失色 → 比光彩、比名声

**9. 力字三兄弟（47、130）**
- 力有不逮（能力够不着，可接规范、手段）｜力不从心（人想做做不到）｜顾此失彼（顾了这头丢那头）

**10. 极悲三兄弟（126）**
- 痛不欲生｜伤心欲绝｜肝肠寸断 —— 都极悲，但要看和谁搭（「悸动」不配「活动」）

**附：对象一错就全错的高频六例（56 拓展）**

| 成语 | 只能用于 |
|---|---|
| 美轮美奂 | 建筑 |
| 汗牛充栋 | 书籍多 |
| 相敬如宾 | 夫妻 |
| 鳞次栉比 | 房屋、船只等排列密集 |
| 巧夺天工 | 人工胜过天然 |
| 良莠不齐 | 人的品质 |

## 八、这一份的口诀

- 意思 / 对象 / 时机，三栏缺一不可；光有氛围感不算
- 良莠不齐管人不管信息
- 宗旨配「不渝」，人配「坚持」，做法才「一如既往」
- 「从而更好地」后面不接事前成语
- 并列的两项必须同层：「广谋良策」配「广开言路」，不配「从善如流」
- 「各」字四兄弟，看褒贬定生死；合成谬误配各行其是
- 谁也替代不了谁＝各有千秋，不是大相径庭
- 并列空只借并列句的色彩，别借下文的评价
- 比大小用相形见绌，比光彩才用黯然失色
- 要长远对比才选杀鸡取卵；唯利是图缺那根时间轴
- 靠它活→皮毛；一起死→覆巢；白挨刀→池鱼
- 极悲三个词都能用，但得配得上下一空
- 作者在讽刺，就别选中性词
- 「看似 X，却 Y」：前空写别人的轻视，后空写真实的重要
- 先问成语打谁，再问句子夸谁

## 九、怎么复习

1. **每天言语前**：挑一组表，遮住「意思 / 对象」两列，只看成语名自测，说不出来的做记号
2. **错题本新增成语**：按本表三栏补一行，别单抄释义；先跑 `_export_chengyu.py` 看有没有新题进册
3. **考前**：只看「我的坑」列和第八节口诀，不回读原题
4. **两次同坑**：同一个成语错第二遍，就单独抄一张小卡（成语＋正确对象＋我当时怎么想的）
