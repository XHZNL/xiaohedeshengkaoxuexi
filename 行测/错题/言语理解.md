## 01 逻辑填空·双空（翻译方法光谱）｜错因：`对应没找到`

**原题**（2026-10-24，第 4 题，全站正确率 57%）

> 毋庸置疑，歪曲原意、难以卒读的译文断不可取；但表达与表意、本意与诗意，如同难以兼顾的跷跷板。正如专家所说：从＿＿的逐字翻译到忠实而又自由的重述，到模仿、再创造、变化、解释性的对应，可以排成一个连续性的光谱……从哪一点出发，都可以产生＿＿的译文。

**我选** C（刻板　妥帖）　**正确** A（严格　精彩）

**正确逻辑**
- 第一空：光谱一端是"自由"，另一端就是"有约束"，即严格；且"刻板"为贬义，"严格"为中性，文段是客观描述，色彩不符。
- 第二空：前文"难以卒读的译文断不可取"，可取的一面即高质量 → 精彩；"妥帖"只是及格线，程度偏轻，托不住"都可以产生"。

**口诀**：两空都读得通时，比**感情色彩**和**程度轻重**，别靠语感。

## 02 成语填空（岭南盆景）｜错因：`成语对象错`

**原题**（2026-10-24，第 8 题，全站正确率 35%）

> 岭南盆景注重自然美与人工美的和谐统一，通过修剪、蟠扎、嫁接等多种技法，将树木、山石、水景等自然元素巧妙地融入盆中，创造出"＿＿"的艺术效果。

**我选** A（一叶知秋）　**正确** D（咫尺千里）

**正确逻辑**
- 文段核心 = 盆小景大、以小见大、缩千里于方寸 → 咫尺千里。
- 一叶知秋 = 由细微迹象**推知趋势**，是"预见"，文段无预见义，使用对象不符。
- 管中窥豹贬义（视野片面）；一日千里指进展快。

**口诀**：成语记三栏——意思 / **适用对象** / 褒贬。字面像，用法未必像。

## 03 中心理解（晒娃与炫娃）｜错因：`选项加戏`

**原题**（2026-10-24，第 14 题，全站正确率 71%）

> "晒"与"炫"之间并没有明确的界限……晒孩子的成绩单、考试名次、各种竞赛奖状，就成了一种"炫"。……"炫娃"还会给朋友圈的亲朋好友带来很多意外的伤害……你的"晒娃"就会让他们充满了挫败感。

**我选** A（过度"晒娃"弊大于利）　**正确** D（"晒娃"要注意其他人的感受）

**正确逻辑**
- 结构：提出晒/炫一步之遥 → 举例区分 → 设问为何炫娃招反感 → 答"招致厌恶 + 给别人带来伤害" → 举例挫败感。中心落在"对别人的影响"。
- A 的"**过度**"文段未提，作者区分的标准是内容性质而非数量；"**弊大于利**"是文段没做的利弊权衡（还承认晒娃能赢祝福）——加戏。

**口诀**：选项范围必须 ≤ 文段范围。凡出现"过度""弊大于利/利大于弊""根源在于"，先当嫌疑人。情绪词不等于结论。

## 04 逻辑填空·双空（网约车订单饱和）｜错因：`对应没找到`

**原题**（2026-10-24，第 15 题，全站正确率 45%）

> 对于热议的"网约车订单饱和"情况不能＿＿，部分城市部分时段或部分月份可能出现短暂性动态饱和，回归到市场供求来说……市场具有自主调节能力，相关部门适时＿＿风险，对于动态调整市场供求关系也将发挥积极作用。

**我选** D（妄下结论　评估）　**正确** B（一概而论　预警）

**正确逻辑**
- 第一空：空格后紧跟一串范围限定"部分城市/部分时段/部分月份/短暂性" → 解释关系，不能用统一标准套全部 → 一概而论。"妄下结论"语气偏指责，与后文理性分析不搭。
- 第二空：**预警风险** 是固定搭配，且"适时预警"是提前提示、防患未然，呼应"发挥积极作用"；"评估"偏事中事后判断。

**口诀**：两空皆通时，**固定搭配定胜负**（政府/评论文章用语优先）。

## 05 语句表达·病句（改革措施 / 能否成才）｜错因：`对应没找到`

**原题**（2026-11-02，Q004，2019 上海）下列句子中没有语病的一句是＿＿。A 检验一项改革措施的合理性，关键是看它能否促进生产力的发展／B 一个人能否成才，要看他有没有信心和毅力／C 汽车本身质量的好坏，也是保证行车安全的一个重要条件／D 如何防备展览会及珠宝店的贵重物品免遭盗窃，是西方国家深感头痛的事。

**我选** A　**正确** B

**① 题型识别**：病句辨析，四句挑唯一无病的——逐句找病点，不是挑读着最顺的。

**② 花生方法论定位**：语病四查——**两面词**（能否／好坏／是否）、**否定词**（防止／避免／免遭）、**数量词**（突破…多／近…以上）、**成分搭配**。见到"能否…有没有"这种双面对双面的形式，先留着当候选。

**③ 解题思路**：A 的落点是"合理性"这**一面**，后面却用"能否"**两面** → 一面对两面。C"质量的好坏"两面 + "保证行车安全"一面 → 同一个病。D"防备…免遭"否定叠加 → 否定不当。B 双面对双面，无障碍。

**④ 排除过程**：B 双对双 ✓｜A 双对单 ✗｜C 双对单 ✗｜D 否定不当 ✗。

**⑤ 答案**：B

**⑥ 易错点**：我把 A 读着顺就当成了对的——**顺 ≠ 无病**。病点九成藏在两面词和否定词上，A、C 都栽在"一面/两面"，D 栽在"免遭"。

**⑦ 同类拓展**：把 A 的"合理性"换成"效果好不好"，同一个句子立刻变正确——病点随搭配变，不随句子变。同批考过的"突破 3 亿多""防止…免于"是同一套。

**⑧ 口诀**：**能否好坏是否，后面必须成双；防止避免免遭，后面不许再否定。**

## 06 逻辑填空·单空（催种催收的四季歌）｜错因：`语义程度偏`

**原题**（2026-11-02，Q009，2019 天津）乡村干部逐渐从以前的催种催收的"四季歌"中＿＿出来，开始思考自己今后的作为。A 解脱　B 释放　C 解放　D 脱离

**我选** C　**正确** A

**① 题型识别**：单空，考动宾搭配 + 语义轻重。

**② 花生方法论定位**：单空题先锁定"空格跟谁搭配、修饰什么"。这里主语是**干部自身**，对象是一堆具体琐事 → 主体的解脱，不是宏大意义上的解放。

**③ 解题思路**：解脱 = 从负担、纠缠中摆脱出来；解放 = 解除束缚使之获得自由，多用于抽象、宏观对象（解放思想、解放生产力）。后文"开始思考自己今后的作为"是放下包袱的轻松语境 → 解脱。

**④ 排除过程**：A 解脱 ✓｜B 释放 是把内含的东西放出来（活力、能量），不接"从…中"｜C 解放 对象偏宏大，个人脱身不用｜D 脱离 中性，无"负担"义。

**⑤ 答案**：A

**⑥ 易错点**：程度与对象双错——解放比解脱重一个量级，对象也偏抽象。我把"解放"当近义词直接用了。

**⑦ 同类拓展**：解脱（个人摆脱负担）／解放（解除束缚，宏观）／释放（放出来，能量）／脱离（离开某种关系，中性）。四个都能跟"出来"搭，区别全在**对象的大小和褒贬**。

**⑧ 口诀**：**人脱小事用解脱，解放思想才用解放。**

## 07 片段阅读·中心理解（负利率是把双刃剑）｜错因：`选项加戏`

**原题**（2026-11-02，Q010，2016 江苏）负利率对居民是双刃剑，对国家则"经济结构调整需要低利率的政策环境……唯有如此，经济转型才会进行得更顺畅"。这段话重在说明：A 负利率其实有利于经济转型／B 现阶段保持低利率对经济有利／C 居民存款可能向实体经济转移／D 近期 CPI 估计不会快速上涨

**我选** A　**正确** B

**① 题型识别**：中心理解（"重在说明"）。

**② 花生方法论定位**：总分结构——先总说"负利率是一把双刃剑"，再分述"对居民"（双刃）、"对国家"（需要低利率环境）。落脚在**国家**这一层。

**③ 解题思路**：末句"唯有如此，经济转型才会进行得更顺畅"= 现阶段保持低利率有好处，直接对应 B。

**④ 排除过程**：B 与末句同义 ✓｜A 把"低利率的政策环境"升级成"负利率"，**概念扩大**；且文段对负利率的定性是"双刃剑"，从没说过"其实有利"｜C、D 文段无据。

**⑤ 答案**：B

**⑥ 易错点**：**"负利率"和"低利率"是两个东西**，我把国家那一层的好话安到了负利率头上 → 加戏。

**⑦ 同类拓展**：凡是选项把原文的 A 词换成更极端的 A′（低利率→负利率、部分→全部、有利→最有利），先当错项处理。这类偷换在中心理解里出现频率仅次于"以偏概全"。

**⑧ 口诀**：**主语、对象、程度三样都对上才叫对应，换掉一个就是加戏。**

## 08 片段阅读·寓意类（苏格拉底摘麦穗）｜错因：`选项加戏`

**原题**（2026-11-02，Q013，2020 云南）苏格拉底让学生走过麦田摘一穗最大的麦穗：一个总想后面还有更大的、空手而归；一个进门就摘了很小的；只有第三个摘了一穗很大、虽不一定最大但结果令人满意。这段文字意在说明：A 生活即思想，思想源于生活实际／B 把握时机是人生快乐的最大诀窍／C 优秀哲学家都以其毕生精力在孕育智慧的田地里耕耘／D 苏格拉底一生注重实践，把哲学的注意力放在生活上

**我选** A　**正确** B

**① 题型识别**：寓言故事类"意在说明"。

**② 花生方法论定位**：故事题把人物**行为**抽象成一条道理，落脚在"结果差异的原因"。三人对照：等最大→空手；急摘小的→不够好；摘了很大且满意→该出手时出手，不贪极致。

**③ 解题思路**：提炼三人差异的教训 → 把握时机／适时决断 → B。

**④ 排除过程**：B 覆盖三人对照 ✓｜A"生活即思想"是元层面的哲学命题，文段没有一句谈思想与生活的关系｜C、D 都在谈苏格拉底这个人，而文段重心是三个学生的**选择结果**。

**⑤ 答案**：B

**⑥ 易错点**：看见"苏格拉底""哲学家"就往哲学命题上归，被故事外壳骗走。故事题的道理落在**行为**上，不落在人物身份上。

**⑦ 同类拓展**：寓意题三问——谁做错了？错在哪一步？怎么做才对？答案通常在第三问。三人对照的材料，正确项必须能同时解释三种结果（等的不行、急的不行、适时的行）。

**⑧ 口诀**：**故事题不读人物读选择：谁选错、为什么错，就是主旨。**

## 09 片段阅读·中心理解（语言是存在的家园）｜错因：`语义程度偏`

**原题**（2026-11-02，Q018，2021 四川）哲学家认为语言是存在的家园，荷尔德林的名句经海德格尔阐释更加升华，"语言是人之存在的明证"，难怪那么多哲学家都对语言研究感兴趣。这段文字意在说明：A 语言即是存在／B 哲学思想的传承／C 语言深刻影响哲学／D 哲学家对语言的看法

**我选** A　**正确** C

**① 题型识别**：中心理解（"意在说明"）。

**② 花生方法论定位**：观点 + 引证 + 结论的三段式，落点看**尾句的态度**——"难怪那么多哲学家都对语言研究感兴趣，甚至还有专门的语言哲学分支"。

**③ 解题思路**：尾句讲的是哲学界因语言而兴、因语言而立分支 → 语言深刻影响哲学（C）。

**④ 排除过程**：C 与尾句同向 ✓｜A 把"家园/明证/担保"升级成**等同**（即是），程度拉满｜B 无据｜D 只描述现象，没有"意在"。

**⑤ 答案**：C

**⑥ 易错点**：文段里"存在"出现太多次，我被高频词带走。高频词 ≠ 主旨词，**作者最后一句才是态度**。

**⑦ 同类拓展**：绝对化词（即是／都是／必然／唯一／完全／不可能）在中心理解里九成是错项，除非文段自己就这么说。

**⑧ 口诀**：**高频词是诱饵，尾句态度才是答案。**

## 10 逻辑填空·四空（世界多极化）｜错因：`对应没找到`

**原题**（2026-11-02，Q020，2021 陕西）随着世界＿＿、经济＿＿、社会＿＿、文化＿＿快速发展……全球迫切需要构建人类命运共同体。A 多极化 全球化 信息化 多样化／B 多样化 多样化 信息化 全球化／C 全球化 多样化 信息化 多样化／D 全球化 信息化 多样化 多样化

**我选** D　**正确** A

**① 题型识别**：四空并列，考**固定表述**。

**② 花生方法论定位**：这类"世界＿、经济＿、社会＿、文化＿"是政策文本的固定四联，四空互为提示，定整串不定单空。

**③ 解题思路**：标准表述是 世界**多极化**、经济**全球化**、社会**信息化**、文化**多样化**，一一对位。

**④ 排除过程**：A 对位全中 ✓｜D 第一空"全球化"抢了经济的位置，且"多样化"出现两次；一串里同一个词出现两次，几乎必错。

**⑤ 答案**：A

**⑥ 易错点**：我按"听着顺"排顺序，没意识到这是背过的固定串——四个词全对、顺序全错，等于零分。

**⑦ 同类拓展**：同类固定串——共商共建共享；政治互信、经济融合、文化包容；多边主义、自由贸易。这类空不靠辨析靠记忆，背一次管三年。

**⑧ 口诀**：**政策四联看整串，重复即错，顺序照背。**

## 11 片段阅读·接语选择（棉纤维与棉籽）｜错因：`对应没找到`

**原题**（2026-11-02，Q023，2026 云南）……许多影响纤维和种子最终表型的基因均在胚珠发育早期集中表达，此时代谢活动也极为旺盛，决定了后续纤维的产量、品质和种子的营养价值。这段文字接下来最可能讲的是：A 棉籽仁及棉籽粕的加工技术／B 棉纤维以及棉籽的经济价值／C 棉花种子的品质以及营养价值判断／D 胚珠发育早期的基因表达与代谢调控机制

**我选** C　**正确** D

**① 题型识别**：接语选择（"接下来最可能讲"）。

**② 花生方法论定位**：只看**尾句的新话题**，前文说过的一律不接——尾句落脚点就是下一段的起点。

**③ 解题思路**：尾句新话题是"胚珠发育早期的基因表达 + 代谢活动旺盛" → 后文接着展开这套机制 → D。

**④ 排除过程**：D 与尾句新话题同一 ✓｜C"品质与营养价值判断"是尾句"决定了…产量、品质和营养价值"的**结果**，已经说完了｜A、B 都是前文已讲的内容。

**⑤ 答案**：D

**⑥ 易错点**：我往前找"棉籽"这个熟人词，选了一个**已经说完的方向**。接语题最忌回头。

**⑦ 同类拓展**：接语题四个坑——已说过的、尾句的上位概念、无关延伸、重复开头。正确项必须与尾句新话题**直接同一**，宁可窄不可偏。

**⑧ 口诀**：**接语只接尾句，前文说得越熟的越不选。**

## 12 片段阅读·细节查找（锂离子电池）｜错因：`选项加戏`

**原题**（2026-11-02，Q024，2020 国考）不过，对大型地面装备来说，锂离子电池功率偏弱是制约其进一步应用的主要因素。因此，未来还需要继续研发高比功率、低成本的锂离子电池。根据这段文字，锂离子电池：A 在大型装备应用方面存在不足／B 在军事应用中具有广泛适用性／C 被各国作为新型电池大力发展／D 是未来战场动力源的发展方向

**我选** D　**正确** A

**① 题型识别**：细节查找（"根据这段文字"）——逐项回原文比对，不归纳。

**⑤ 答案**：C

**⑥ 易错点**：我数词频，谁出现得多选谁，把"个人信息"这个**论据词**当成了主题词。关键词题考的是"能罩住全篇"，不是"出现最多"。

**⑦ 同类拓展**：干扰项常用两招——把论据词塞进选项、把只在某一句出现的词塞进选项。检验办法：拿这个词去替换标题，读一遍还成立吗。

**⑦ 同类拓展**：细节题三大送分陷阱——方向反（A 到 B 写成 B 到 A）、程度加码（可能→必然）、主体偷换（色素体相似→羽色相似）。

**② 方法论定位**：花生排序三步：① 定首句（指代词、关联词开头的全排除）② 抓捆绑（指代、转折、并列）③ 定尾句（"可见""因此"收）。

**⑤ 答案**：C

**⑥ 易错点**：我盯着②⑥①这组"举例子"排得挺顺，就把整段倒装了——**只验了局部捆绑，没验全局的总结句位置**。排序题先钉死首句和尾句，中间才轮得到捆绑。

**⑦ 同类拓展**：尾句特征词：可见、因此、所以、总之、正是……；首句特征词：随着、近年来、从……看。这两类词一出现，位置基本就定了。

**⑧ 口诀**：**先钉首尾，再抓捆绑；"可见"打头必是错，"这种"指代必向前。**

**① 题型识别**：主旨概括，议论＋举例结构，例子服务的那个观点才是中心。

**② 方法论定位**：**"比如"之后全是论据**，中心句在"比如"之前那句——"产品的停产或者迭代大都与用户的消费习惯和追求新事物的欲望有关"。

**③ 解题思路**：这句话的主语是"产品迭代/停产"，原因是"用户消费习惯"；例子再补一层：相机行业因此**改变研发方向**（转型走高端）。合起来：消费端的变化推动生产端调整策略 → D。

**⑥ 易错点**：A 读着最"稳"，因为它什么都能装——**选项越空泛越像对的，这是主旨题最大的假朋友**。中心句已经说清了"谁影响谁"，就不能退回到"有影响因素"。

**⑦ 同类拓展**：主旨题常见空壳词：影响因素、重要意义、发展趋势、存在问题。见到这类词先问一句：它比原文多说了什么？说不出就是废项。

**⑧ 口诀**：**"比如"前面是观点，后面是证据；空壳选项最像答案，也最该划掉。**

**② 方法论定位**：**"这说明/可见"前有什么，横线就总结什么**——不能总结前文没提的内容。

**⑤ 答案**：B

**⑥ 易错点**：C 的"越来越重要"是我读数据时的直觉，觉得"贡献率涨了＝更重要"，很顺——**但顺不等于对位**。填空要的是"这句话能不能被前面那组数据直接推出来"，不是"这句话对不对"。

**⑦ 同类拓展**：数据结论题的高频对应：贡献率高、增速快→引擎/动力；占比大→支柱/主体；覆盖广→基础。看到"引擎"先找"增长、拉动"这类词，找不到就别选。

**⑧ 口诀**：**"这说明"是翻译题：前面给数字，后面给角色；数字里没有的角色，别硬安。**

**⑦ 同类拓展**：定义角度题常见答案：本质属性（是什么）、形成过程（怎么来）、社会功能（有什么用）、文化价值（意味着什么）。判据永远是最后一句的落点。

## 55 细节判断·相符（帕克太阳探测器）｜错因：`对应没找到`

**② 方法论定位**：细节题三条铁律：主语不能扩大、程度不能加码、时态不能提前。

**③ 解题思路**：C 对应"在严酷的高温和辐射条件下"——承受高温与辐射，原文直陈 ✓。B 把主语从"帕克探测器"扩成了"美国发射的太阳探测器"（美国发射的探测器不止一个，不能都算"离太阳更近"），属于**主语偷换** ✗。

## 56 逻辑填空·三空（信息来源芜杂）｜错因：`成语对象错`

## 63 逻辑填空·关联词（欧阳修）｜错因：`语义程度偏`

**原题**（2026-11-12，Q050，2022 深圳）欧阳修＿＿文章冠绝一时，其为政措施＿＿颇具创新意识。＿＿一生仕途坎坷、三遭贬谪，但他始终宠辱不惊，晚年＿＿是旷达潇洒。

**② 方法论定位**：先定关系再选词。文章好、政绩好＝并列；后面已有"但"，前面只能让步；"宠辱不惊""旷达潇洒"两个近义评价＝并列。

**③ 解题思路**：
1. 前两空：两件事并列，谁也不比谁重 → 不仅……也……
2. 第三空：紧接"但"，只能填"尽管"，不能填本身就是转折的"不过"。
3. 第四空：与前一分句并列 → "也"。

- B 四空全对 ✓

**⑥ 易错点**：我只盯前两空，"不仅也"和"不但还"读着都通，后两空直接跳过。错因：`语义程度偏`——"不但…还"把并列说成递进，硬给政治能力加了一层"更"。

**⑦ 同类拓展**：见空格后面已有"但/却/然而"，前面只能"尽管/虽然"；两个转折词连用必错。表并列用"也"，表递进才用"还/更"。

**⑧ 口诀**：**先看空后有没有"但"，有就只能是"尽管"。**

- A 三项都挂在"科幻文学"名下 ✓

**⑤ 答案**：A

**⑥ 易错点**：我选 C，多算了最后一句。错因：`选项加戏`——把"科幻作家的能力"塞进了"科幻文学的功能"。

## 74 逻辑填空·双空（耀州龙泉青瓷）｜错因：`语义程度偏`

**原题**（2026-11-12，Q079，2018 联考陕西）中国文化讲究因果，陶瓷上明显能看出地域文化的影响。同为宋代青瓷，北方耀州青瓷呈橄榄绿，强调＿＿；南方龙泉青瓷呈梅子青，表现＿＿；演绎各自地方性格特点。

**我选** C（沉着　俏皮）　**正确** B（深沉　柔婉）

**① 题型识别**：逻辑填空双空，两空都是"颜色→性格"的对应。

**② 方法论定位**：两空得是同一量级的性格词，还得贴各自颜色。橄榄绿偏暗偏厚，梅子青青碧柔和；两种都是绿系，差异不能拉太大。

**③ 解题思路**：
1. "橄榄绿"厚重稳静 → 深沉。
2. "梅子青"莹润优雅 → 柔婉。
3. 两词都在性格层面，且都是收敛型，并排放得住。

**④ 排除过程**：
- A 豪放＋婉约，反差过大，同一族绿系撑不起"豪放" ✗
- C "沉着"是镇静、不慌不忙，是状态不是性格；"俏皮"讲活泼机灵，与梅子青的雅不合 ✗
- D "稳重"可留，"活泼"是有活力、动感，与梅子青气质不符 ✗
- B 深沉＋柔婉，两空同族、都贴色 ✓

**⑤ 答案**：B

**⑥ 易错点**：我选 C，只图"沉着"够暗、"俏皮"有点反差。错因：`语义程度偏`——"沉着"是状态词不是性格词，"俏皮"跟梅子青差得太远，两空风格被拉开了。

**⑦ 同类拓展**：双空填性格词，先看两空能不能并排放；一文一野、一沉一跳，基本都不对。

**⑧ 口诀**：**两空要同族：颜色多像，性格就得多近。**

## 75 逻辑填空·三空（中华文明韧性）｜错因：`对应没找到`

**原题**（2026-11-12，Q084，2023 内蒙古）中华文明早已形成以德治为主的"天下一家""世界大同"理念，这个理念深深＿＿在中国人的心目中，以至于见到恃强凌弱就极其反感。因此，中华文明有很强的＿＿，因为它由同一的理念凝聚起来，而不是由武力和强迫＿＿在一起的，因而有强大生命力，遇危机能一次次重生。

**我选** D（植入　延续性　对接）　**正确** A（浸润　韧性　拼凑）

**① 题型识别**：逻辑填空三空。

**② 方法论定位**：第二空后面紧跟解释句——"因而有强大的生命力，能够在遇到危机时，一次次重生"，这就是第二空的答案提示；第三空与"凝聚"构成反义对照。

**③ 解题思路**：
1. 能一次次从危机里重生 → 韧性。
2. 与"由同一理念凝聚"相反、靠外力硬合 → 拼凑。
3. 理念进人心是慢慢渗进去 → 浸润。

**④ 排除过程**：
- B "嵌入"可留，但"感召力"是感化召唤，文中没这层；"缝合"偏医疗拼接，反义不准 ✗
- C "扎根"可留，"粘性"是两物相粘不易分离，接不住"生命力、重生" ✗
- D "植入"常配广告、器官，且含被动接受，文中是人民主动信服；"延续性"只说延续，没有顽强抗危机；"对接"是两头相接，不是硬凑 ✗
- A 三空全对 ✓

**⑤ 答案**：A

**⑥ 易错点**：我选 D，被"延续性"这个听着大气的词带走。错因：`对应没找到`——第二空的答案句就写在后半句，"一次次重生"四个字我没回头看。

**⑦ 同类拓展**：三空题里某空后面紧跟"因为/因而/即"的解释句，那一空最好定，先做它。

**⑧ 口诀**：**空后有解释句，先做那一空。**

**② 方法论定位**：每项都回原文对主语和范围；推知只推一步，不跨主体。

**③ 解题思路**：
1. 原句"但当黑暗条件回归时，颜色也会回归"——暗下来颜色回来，也就是有光。
