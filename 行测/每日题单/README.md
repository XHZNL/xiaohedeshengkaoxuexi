# 每日题单

> 每天一份，240 题，按模块分段、按 20 题分组。**答案在文件末尾，做完再看。**

---

## 一、这是什么

从本地题库（515 套真题，58,890 题）里筛出来的**纯文字题**，每天按固定配比抽一份，题目打乱、不重复。

题库本体 354 MB 不在仓库里，只在这里保存每天的题单。

| 段 | 题量 | 细分 |
|---|---|---|
| 一、言语理解 | 100 | 片段阅读 60 · 逻辑填空 30 · 语句表达 10 |
| 二、判断推理 | 90 | 定义判断 45 · 逻辑判断 35 · 类比推理 10 |
| 三、数量关系 | 50 | 纯文字题 |

**不含**：常识政治（靠每天 15 条背诵）、资料分析、图形推理（这三块在粉笔做）。

## 二、怎么用

1. 打开当天的 `.md`，从 `第 1 组` 往下做
2. **答案写在纸上**，按 Q001–Q240 顺序，20 个一行
3. 每组做完歇一分钟，顺手核一下这 20 题
4. 全部做完翻到末尾的「答案」区，一行一行对
5. 错的把题号发出来（如「Q037 错了，我选 B」），按八栏讲 + 记进错题本

## 三、结构

每份题单是 13 个组：

```
## 一、言语理解（100 题）      第 1–5 组
## 二、判断推理（90 题）       第 1–5 组（最后一组 10 题）
## 三、数量关系（50 题）       第 1–3 组
```

组标题带题号区间（`第 1 组（Q001–Q020）`），方便定位，也方便报错题。

## 四、题源与去重

- 题库来自 `ERRRC/xingcezhenti`（515 套 / 58,890 题 / 2016–2026）
- 只取**题干无图**的题（图推、图表材料全部剔除），共 18,514 道可用
- 每道题按「卷名 + 题号」记账，出过不再出现
- 池子按现配比约 50 天用完，数量关系最先见底（39 天）
