## 三、怎么用

**两条路，别混着走。**

| 你在干什么 | 用什么 |
|---|---|
| 按题型专项练 | 去 [题单/](../题单/README.md)，题单里每道题的「卷源」直接链到本目录 |
| 整套掐时间 | 直接开这里的一份，从给定资料读到最后一题，150 分钟 |

**写习题的流程**（跟 [申论-做题方法.md](../申论-做题方法.md) 对齐）：

1. 读给定资料，不做标记
2. 审题：题型、身份、对象、字数、要求
3. 逐段找点，边找边编号
4. 列提纲 → 写答案
5. 发鲸鱼娘批改（按采点率 / 分类 / 格式 / 语言 / 立意五个维度）
6. 一周后同一道题重写一遍

## 四、注意

- **老卷不一样。** 2000–2009 的国考卷只有 2–3 题，有些还带"填横线""写标题"的老题型；拿来熟悉材料可以，别当模考标准。
- **2020 年起辽宁分 A/B 类**；2022 年起国考加行政执法卷。
- 题干、材料、分值、字数都是从真题整理稿来的，**个别回忆版可能有出入**，遇到明显不对劲的（比如某题材料对不上）跟我说，我回头核。
- 答案那部分我没带上来 —— 想要对照，本地那份 `申论/真题库/` 里有。
