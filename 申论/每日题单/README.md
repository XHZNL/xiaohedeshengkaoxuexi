# 申论每日题单

> 建：鲸鱼娘 2026-11-09
> 跟行测那套一个用法：**要练了，点一下，出一道。** 不排进度、不催、不补历史。

---

## 一、怎么出

| 你要 | 怎么办 |
|---|---|
| 出今天这道 | 双击 `A:\dsh-work\出申论题.bat`，或者跟我说一声 |
| 指定题型 | `.bat` 加参数不方便，直接跟我说「出个公文」「出个大作文」 |
| 想重写一道做过的 | 说「单一题 001 再写一遍」，我把那道重新端出来 |
| 换一天补 | 一般不用 —— 缺了就缺了，别攒债 |

每份生成两样东西：

- `YYYY-MM-DD.md` —— 题面 + 该卷对应的材料全文。手机能看，想抄要点就抄。
- `练习台-申论-YYYY-MM-DD.html` —— 电脑上做。左材料右题，底下格子打字，自动存，写完导出 txt 给我。

`.json` 是给练习台喂数据的，不用管。

---

## 二、抽题规则

- **来源**：辽宁 6 : 国考 4。最近 10 道里辽宁不够 6 道，就优先辽宁。
- **题型**：默认只出小题，按 单一 4 : 公文 3 : 综合 3 : 对策 2 轮着来，缺哪类补哪类。**大作文不自动出**，你自己喊。
- **冷却 14 天**：做过的题半个月内不再出现。过了就能重写 —— **同一道题写第二遍，比写十道新的有用**。
- **排序**：辽宁优先、年份倒序。所以前期抽到的基本是 2024–2026 的辽宁卷。
- 题号跟 [题单](../题单/README.md) 里那五本册子**完全一致**，报「单一题 001」我就知道是哪道。

---

## 三、做完

1. 练习台点「导出 txt」或「复制」，发我。
2. 我按 采点率 / 分类 / 语言 / 结构（大作文加立意）逐条挑，不给「总体不错」。
3. 一条一记进 [批改记录](../题单/批改记录.md)，带上错点标签。
4. 攒够三五条，你就能看见自己翻来覆去栽在哪儿 —— 那时候再谈提速。
