## 一、这一份是什么

- 题面 + 每题折叠的参考答案与答案逻辑图（`<details>` 默认收起，做题时看不见答案）
- 参考答案来自粉笔题库采集稿，**不是官方答案**——申论考试院从不公布标准答案。原文件 YAML 里也写着「粉笔题库整理版本，未认证为官方原卷」
- 采集时间 2026-10-25；题号按粉笔练习卡顺序连续编号，与原卷题号可能有出入
- 结构：给定材料 1–4 → 作答要求（第 1–4 题，带分值、关联材料、字数）→ 每题后折叠答案与解析

## 二、怎么用

先开 [真题/辽宁/2026年辽宁省考申论（A类）.md](../真题/辽宁/2026年辽宁省考申论（A类）.md) 那份干净题面写，写完再翻这里对答案。

顺序别反——先看答案再写，等于白写一遍。

## 三、加新的怎么办

往本目录扔一份 md，把它的 `assets-fenbi-xxxxx/` 图目录一起放同级（md 里按相对路径引用）。
同步用的 `_sync_docs.py` 已经把「真题答案」算进申论白名单，md 会自动同步；**图要手工拷**——同步脚本只处理 .md。

## 四、完整库在哪

完整答案库在本地 `申论/真题库/`：辽宁 20 份（含答案）、国考原卷 49 份、国考带答案 41 份、B5 排版 PDF 49 份，共 110 份 Markdown + 271 张答案图 + 49 份 PDF。
本目录只是从它里面挑出来公开的一小部分；整库约 22 MB，不整库入库。
