## 二、怎么用

**一条铁律：一次只做一道。**

申论不是刷量，是刷同一道题的第二遍。方法文档写得很直白 —— 一篇改三遍，胜过写三篇新的。

| 你手上有什么 | 做什么 |
|---|---|
| 想练某一类题 | 直接翻对应那本，从 001 往下 |
| 不知道弱在哪 | 四本小题各做一道（001），一晚上就知道哪本最难看 |
| 文章写不出来 | 先别碰 05，把 04-公文 的 001–004 写熟 —— 会写提纲的人，才写得出大作文的分论点 |
| 快考试了 | 从 05 里挑近三年辽宁的，掐 60 分钟整套写 |

**每道题走完这五步：**

1. 开卷源，读材料，不划线
2. 审题：题型、身份、对象、字数、要求（30 秒，别省）
3. 逐段找点，边找边在纸上编号
4. 列提纲 → 写答案
5. 发我批改

## 三、每周排程

方法文档的节奏是 **2 次小题 + 1 次大作文 + 1 次改旧文**。前五周做「套」（只写框架，不写全文），第六周起转「全写」。

| 周次 | 小题 A | 小题 B | 大作文 | 改旧文 |
|---|---|---|---|---|
| 第 1 周 | 单一 001 | 综合 001 | 大作文 001 | — |
| 第 2 周 | 公文 001 | 对策 001 | — | 改第 1 周那道小题 |
| 第 3 周 | 单一 002 | 综合 002 | 大作文 002 | 改第 1 周的大作文 |
| 第 4 周 | 公文 002 | 对策 002 | — | 改第 2 周的公文 |
| 第 5 周 | 单一 003 | 综合 003 | 大作文 003 | — |
| 第 6 周起 | **转全写**：小题掐 40 分钟，大作文 60 分钟，同一道题隔周重写 | | | |

> 排程只是起手式。做顺了你自然会想跳着来 —— **跳可以，但每次只跨一步**，别一口气排满一周。

## 四、注意

- **老题不一样。** 2000–2009 的国考卷题型跟现在差得远（有的题只有两三问、有的要求"填横线"），拿来熟悉材料可以，别当模考标准。
- **复合题按主问题归类。** 比如"梳理问题并提出建议"，我归在 03-提出对策；题干里两问都写着，做的时候两问都要答。
- **答案不是官方的。** 粉笔采集稿，对照思路用。
- 题号（001、002…）**固定不变**，以后新增题只往后接，方便你说"我做的是单一题 037"。

## 五、跟我配合

写完发我，报「哪一本 · 第几号」（例如「单一题 012」）。

我按四个维度挑：**采点率 / 分类 / 语言 / 结构**，大作文加**立意**。不给"总体不错"，逐条说，你改完再发我看一遍。

批改记录攒在 [批改记录.md](批改记录.md)，看自己是不是总栽在同一个地方。
