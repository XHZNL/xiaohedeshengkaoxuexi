# 申论

> 行测和申论是两套本事：行测靠刷、靠快；申论靠找点、靠写。所以分开放。

## 目录

| 文件 | 内容 |
|---|---|
| [申论-做题方法.md](申论-做题方法.md) | 五类题型套路（单一题 / 综合分析 / 提出对策 / 公文 / 大作文）+ 规范表达 + 练习节奏 |

## 这个文件夹以后放什么

- **素材**：人物、政策、金句，按主题归档（乡村振兴 / 基层治理 / 数字经济…）
- **习作**：每周写的完整答案，按日期存
- **批改记录**：每次发我看完的点评，攒着看自己的毛病是不是总在同一个地方

## 练习节奏

每周 2 次小题 + 1 次大作文 + 1 次只改旧文。

**申论不塞进每日题单**——它是写出来的，不是刷出来的。
