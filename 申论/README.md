## 这个文件夹以后放什么

- **素材**：人物、政策、金句，按主题归档（乡村振兴 / 基层治理 / 数字经济…）
- **习作**：每周写的完整答案，按日期存
- **批改记录**：每次发我看完的点评，攒着看自己的毛病是不是总在同一个地方

## 练习节奏

每周 2 次小题 + 1 次大作文 + 1 次只改旧文。前五周只写框架，第六周起转全写。

**申论不塞进每日题单**——它是写出来的，不是刷出来的。
