# 申论 · 做题方法

> 整理：鲸鱼娘　｜　2026-11-01　｜　体系：花生十三（材料为王 + 题型套路 + 规范表达）
> 定位：100 分 / 150 分钟。**不是写作文，是「阅读理解 + 信息提炼 + 规范表达」。**
> 答案 80% 在材料里，考的是找得到、提得准、写得对。

---

## 〇、先认清三件事

**① 申论不是作文比赛。** 评分靠要点，不靠文采。要点齐、分类清、话说得规范，分数就上去了。

**② 五类题，五个套路。** 每一类都有固定结构，练熟了是机械动作，不需要灵感。

**③ 卷面是分。** 字迹工整 1–3 分，字数超了扣分，这两项是白送和白丢。

### 题型与分值

| 题型 | 题量 | 分值 | 核心能力 |
|---|---|---|---|
| 单一题（归纳概括） | 1–2 | 10–20 | 找点 + 概括 |
| 综合分析 | 1 | 15–20 | 分析 + 逻辑 |
| 提出对策 | 0–1 | 15–20 | 问题 → 对策 |
| 公文写作 | 1–2 | 20–25 | 格式 + 内容 |
| 大作文 | 1 | 35–40 | 立意 + 结构 + 论证 |

### 评分怎么来的

- **要点分**：每个关键词 1–3 分（占大头）
- **逻辑分**：分类合理、层次清晰 2–5 分
- **格式分**：公文格式正确 2–5 分
- **语言分**：表达规范、无语病 2–5 分
- **卷面分**：字迹工整 1–3 分

**一句话：分在点上，不在句子上。**

### 五条铁律

1. **材料为王**——答案必须来自材料，不自己编
2. **关键词优先**——用材料原词，不随意替换成同义词
3. **分类作答**——同类合并，异类分开
4. **序号化**——①②③ 或 一、二、三，让阅卷人一眼看到
5. **字数控制**——不超字数，也不写太少

## 一、单一题（归纳概括）

**识别**：概括……的问题 / 原因 / 影响 / 做法；归纳……的特点 / 表现 / 变化；总结……的经验 / 启示。

### 五步法

**第 1 步：审题**（30 秒）
圈四样东西：**作答对象**（概括什么）、**范围**（哪则材料）、**字数**、**要求**（全面/准确/有条理）。

**第 2 步：找点**（最主要的时间花在这）
逐段扫，抓三类信号词：
- **问题**：不足、缺乏、滞后、薄弱、缺失、不到位、不完善
- **原因**：因为、由于、源于、归因于
- **影响**：导致、使得、促进、推动、加剧、恶化
- **做法**：建立、完善、推进、加强、创新（抓动词）

> 关联词后面才是重点：**因为／所以／导致**。

**第 3 步：概括**
删修饰、留核心、同类合并。
> 原文：「由于资金投入不足，导致基础设施建设滞后，影响了居民生活质量。」
> 概括：①资金投入不足 ②基础设施滞后 ③影响生活质量

**第 4 步：分类**（拿逻辑分的关键）
四种分法，挑一种用到底：
- 按主体：政府 / 企业 / 社会 / 个人
- 按领域：经济 / 政治 / 文化 / 社会 / 生态
- 按层面：思想 / 制度 / 执行 / 监督
- 按时间：过去 / 现在 / 未来

**第 5 步：书写**
```
一是××。具体表现为：①……；②……；③……。
二是××。具体表现为：①……；②……；③……。
三是××。具体表现为：①……；②……；③……。
```

### 四种作答对象速查

| 对象 | 找什么 | 注意 |
|---|---|---|
| 问题 | 负面表述 | 别把"对策"混进来 |
| 原因 | 因果词 | 分主客观、内外 |
| 影响 | 结果词 | 分积极/消极两类 |
| 做法 | 动词 | 统一写成动宾结构 |

### 易错
脱离材料自己编｜整段照抄不概括｜要点堆砌不分类｜超字数｜漏点

## 二、综合分析（最难拿满分，但有套路）

**四小类，四个结构：**

| 类型 | 问法 | 结构 |
|---|---|---|
| 词句理解 | 谈谈对"××"的理解 | 是什么 → 为什么 → 怎么办 |
| 观点分析 | 对"××观点"进行评价 | 表态 → 理由 → 对策 |
| 比较分析 | 比较 A 和 B 的异同 | 相同点 → 不同点 → 启示 |
| 关系分析 | 分析 A 和 B 的关系 | 各自含义 → 相互关系 → 如何处理 |

**步骤**：审题定角度 → 材料里定位 → 多角度展开 → 按结构组织 → 分层书写。

**两个模板（直接套）**

```
"××"是指……（表层含义）。具体表现为：①……；②……；③……。
其原因是……（深层分析）。
因此，我们应该……（对策启示）。
```

```
此观点是正确的 / 错误的 / 片面的。
理由如下：①……；②……；③……。
因此，我们应该……（对策）。
```

> 表态这一步别省。观点分析题没表态，直接丢分。

## 三、提出对策

**识别**：针对……问题提出对策；如何解决……；请就……提出建议。

### 对策从哪来

**直接对策**（材料里明说了）："应该""需要""必须"后面的话、各地经验做法、专家建议。
**间接对策**（反推，考场上更常用）：
- 问题 → 解决这个问题的动作
- 原因 → 消除这个原因的动作
- 教训 → 避免这个教训的动作

### 怎么写才算"具体"

```
❌ 加强监管
✅ 加强市场监管，建立健全监管机制，加大对违法行为的查处力度
```

**格式：动宾结构 + 具体做法**。只有动宾结构那四个字，是"空对策"，拿不到高分。

### 八个万能维度（想不出对策时按这个扫）

| 维度 | 方向 |
|---|---|
| 思想 | 加强宣传教育，提高认识 |
| 制度 | 完善法律法规，健全制度 |
| 组织 | 加强领导，明确责任 |
| 人才 | 加强队伍建设，培养人才 |
| 资金 | 加大投入，保障经费 |
| 技术 | 加强研发，应用新技术 |
| 监管 | 加强监管，严格执法 |
| 监督 | 加强社会监督，畅通渠道 |

> ⚠️ 万能维度是"兜底"，不是"主菜"。**材料里有的必须写，材料里没有的才用维度补。**

## 四、公文写作（格式分最好拿，也最好丢）

### 完整格式

```
           标题（居中，发文机关+事由+文种）
称呼（顶格，加冒号）：
    正文：开头（为什么）→ 主体（是什么/怎么做）→ 结尾（希望要求）
                              落款（右下）
                          日期（右下）
```

### 常考文种（15 种，先记这 6 个）

| 文种 | 场景 | 结尾 |
|---|---|---|
| 通知 | 布置工作 | 请认真贯彻执行 |
| 倡议书 | 号召行动 | 让我们共同行动起来！ |
| 讲话稿 | 会议发言 | 谢谢大家！ |
| 工作方案 | 部署任务 | 设指导思想/目标/任务/保障 |
| 公开信 | 公开回应 | 感谢理解与支持 |
| 短评/编者按 | 点评介绍 | 无固定结语 |

### 四个模板（背下来直接套）

**通知**
```
关于××的通知

××单位：
  为……（目的），现就××事项通知如下：
  一、……
  二、……
  三、……
  请认真贯彻执行。

××单位
××××年××月××日
```

**倡议书**
```
关于××的倡议书

广大市民朋友们：
  ……（背景）。为此，我们倡议：
  一、……。
  二、……。
  三、……。
  让我们共同行动起来，……！

××单位
××××年××月××日
```

**讲话稿**
```
在××会议上的讲话

同志们：
  今天我们召开……会议，主要目的是……。
  一、认清形势，……。
  二、明确任务，……。
  三、狠抓落实，……。
  谢谢大家！
```

**工作方案**
```
关于××的工作方案

  为……，特制定本方案。
  一、指导思想
  二、工作目标
  三、主要任务（一）……（二）……
  四、保障措施（一）加强领导（二）明确责任（三）强化监督
```

### 五个要点
格式齐全（标题/称呼/落款/日期）→ 开头点题 → 主体分条 → 语言书面 → 结尾得体。

## 五、大作文（35–40 分，成败在这）

### 审题立意（三步）

1. **审题干**：给的关键词、要求的角度
2. **审材料**：材料主旨、核心观点
3. **审要求**：字数、文体、特殊要求

**三种立意法**
- 关键词法：题干给"创新"→ 立"以创新驱动发展"
- 材料主旨法：提炼材料的核心观点当论点
- 角度切入法：从"怎么办"切（对策型最好写、最不容易偏）

**立意的四条标准**：正确（合主流价值观）、明确（不含糊）、深刻（有层次）、新颖（不落俗套）。

### 结构：五段三分（最稳）

```
第一段 开头（150 字）   引出话题 + 提出总论点
第二段 分论点一（250 字）
第三段 分论点二（250 字）
第四段 分论点三（250 字）
第五段 结尾（150 字）   总结 + 升华
```

另两种：递进式（是什么→为什么→怎么办）、对比式（正→反→综合）。**第一次写就用五段三分。**

### 分论点从哪来

按维度切，三个维度各出一个：
- 主体：国家 / 社会 / 个人
- 领域：经济 / 政治 / 文化 / 社会 / 生态
- 层面：思想 / 制度 / 行动

> 例：乡村振兴 →
> 产业兴旺是基础（经济）｜生态宜居是关键（生态）｜乡风文明是灵魂（文化）

### 四种论证（每个分论点挑一种）

| 方法 | 结构 |
|---|---|
| 举例 | 论点 + 例子 + 分析 + 小结 |
| 道理 | 论点 + 道理 + 阐释 |
| 对比 | 论点 + 正面 + 反面 + 分析 |
| 引用 | 论点 + 名言/政策/数据 + 阐释 |

**举例的写法**（一个例子 70 字以内）：
> 创新是引领发展的第一动力。以华为为例，面对技术封锁坚持自主创新，研发投入连年增长，最终在 5G 领域取得领先。这说明，只有坚持创新，才能在竞争中立于不败。

### 开头三选一

```
背景式：当前，……（背景）。然而，……（问题）。因此，……（论点）。
引用式："……（名言）。"这句话告诉我们……。在……背景下，……（论点）。
设问式：面对……问题，我们该如何应对？答案在于……（论点）。
```

### 结尾三选一

```
总结式：综上所述，……。让我们……（号召）。
展望式：展望未来，……。只要我们……，就一定能……。
引用式："……（名言）。"……（结合论点）。让我们……。
```

### 大作文七坑
偏题｜论点不清｜结构乱｜论证空（只有论点没论据）｜套话连篇｜字数不足｜不联系材料

## 七、易错点总表

| 坑 | 说明 |
|---|---|
| 脱离材料 | 自己发挥，不在材料找 |
| 照抄原文 | 不概括，整段搬 |
| 不分类 | 要点堆成一团，丢逻辑分 |
| 空对策 | 只写"加强监管"，不写怎么做 |
| 公文缺格式 | 少称呼、少落款、少日期 |
| 大作文偏题 | 立意脱离题干材料 |
| 论证空洞 | 只有观点，没有例子和道理 |
| 字数失控 | 超了扣分，少了也扣 |

## 八、练习节奏（跟行测不一样）

申论是"写"出来的，不是"刷"出来的。**别塞进每日题单**，单独排：

| 频率 | 内容 | 用时 |
|---|---|---|
| 每周 2 次 | 一次小题（单一题 / 综合 / 公文轮换） | 40 分钟 |
| 每周 1 次 | 大作文 | 60 分钟 |
| 每周 1 次 | 只改上一周的旧文 | 30 分钟 |

**四个阶段**

1. **抄**（第 1–2 周）：抄 3 篇高分答案，感受要点密度和语言
2. **套**（第 3–5 周）：只写框架，不写全文——审题、找点、列提纲
3. **全写**（第 6 周起）：完整作答，掐时间
4. **改**（贯穿）：同一道题隔一周重写一次，比较两次的差别

**改比写更值钱。** 一篇改三遍，胜过写三篇新的。

## 九、口诀

- **本质**：材料为王，要点优先，分类作答
- **单一题**：审题 → 找点 → 概括 → 分类 → 书写
- **综合题**：是什么、为什么、怎么办
- **对策题**：问题反推、原因反推、教训反推
- **公文**：标题、称呼、正文、落款、日期，一个都不能少
- **大作文**：审题立意、五段三分、论点带例证
- **表达**：动宾结构，书面语言，短句为主

## 附：跟我配合的方式

**你写完发我**，我按阅卷的五个维度给你打分：

1. 采点率（该有的要点有没有，缺哪几个）
2. 分类是否合理
3. 公文格式是否齐全
4. 语言是否规范（哪句是口语、哪句能换成规范表达）
5. 大作文的立意站不站得住

不给"感觉不错"这种评语，逐条说问题，然后你自己改。**改完再发我看一遍。**
